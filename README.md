# 🚀 Desafio 1: Console App de Cadastro de Clientes (C# & .NET)

Projeto desenvolvido no âmbito da minha jornada de estudos em **Análise e Desenvolvimento de Sistemas (ADS)**, com foco em C# e nos fundamentos da Orientação a Objetos (POO).

## 📂 O que contém este projeto:
- **Cliente.cs**: Classe de modelo (`class`) que serve de molde para os dados do cliente, utilizando propriedades encapsuladas (`get; set;`).
- **Program.cs**: Lógica principal de execução no console, responsável por interagir com o utilizador (`Console.WriteLine` e `Console.ReadLine`) e realizar conversões de tipos (`Convert.ToInt32`).

## 🛠️ Tecnologias e Ferramentas:
- **Linguagem**: C# (.NET)
- **IDE**: Visual Studio 2022
- **Controlo de Versão**: Git & GitHub
